# CGV 용산 IMAX Playwright 자동화 보조

기본 설정은 다음과 같습니다.

- 영화: 오디세이 (`movNo=30001323`)
- 극장: CGV 용산아이파크몰 (`siteNo=0013`)
- 상영관: IMAX관 (`scnsNo=018`)
- 날짜: 2026-08-26
- 회차: 4회차
- 인원: 2명
- 좌석 우선순위: J → I → L, 중앙 20-21부터 바깥쪽으로 연속 2자리 탐색
- 결제 자체는 자동으로 하지 않음

## 설치

VSCode에서 이 폴더를 연 다음 터미널에서:

```bash
npm install
npx playwright install chromium
```

Chrome을 직접 사용하도록 코드가 설정되어 있으므로 Chrome이 설치되어 있어야 합니다.

## 실행

```bash
npm start
```

또는:

```bash
node cgv.js
```

## 로그인

프로그램을 실행하면 **가장 먼저 아래 CGV 로그인 페이지를 엽니다.**

`https://cgv.co.kr/mem/login?returnUrl=%2Ftme%2FtmeShowMore`

아이디, 비밀번호, 자동입력 방지문자는 브라우저에서 **직접 입력하고 로그인 버튼도 직접 누릅니다.**
로그인 완료가 감지되면 그때부터 자동으로 8/26 용산 IMAX 편성 감시를 시작합니다.

`browser-data` 폴더에는 Playwright용 브라우저 프로필이 저장되므로 로그인 세션이 유지될 수 있습니다.
세션이 남아 있으면 다음 실행에서는 로그인 페이지가 자동으로 넘어갈 수도 있습니다.

CAPTCHA나 추가 인증을 우회하는 기능은 포함되어 있지 않습니다.

## 동작

1. 프로그램 실행
2. CGV 로그인 페이지 자동 이동
3. 사용자가 아이디 / 비밀번호 / 자동입력 방지문자를 직접 입력하여 로그인
4. 로그인 완료 감지
5. 8/26 용산 IMAX 오디세이 4회차를 반복 조회
6. 4회차가 생기면 `rtktCntlYn` 확인
7. `N`이 되면 실제 예매 화면으로 이동
8. IMAX 4회차 클릭
9. 2명 선택
10. 좌석 선택 화면 진입
11. 다음 우선순위로 2연석 탐색
    - J20-21
    - I20-21
    - L20-21
    - J19-20
    - I19-20
    - L19-20
    - J21-22
    - ...
12. 두 좌석 클릭
13. `선택완료` 클릭
14. 이후 결제는 직접 진행

## 주의

CGV 웹페이지/API 구조가 변경되면 selector나 API가 동작하지 않을 수 있습니다.
로그인, 대기열, CAPTCHA, 추가 본인인증 등의 보호 절차는 직접 처리하세요.
과도하게 짧은 주기로 요청하지 않도록 기본 감시 주기는 편성 5초, 예매통제 2초로 설정되어 있습니다.
